# Road Event Watch — team website

Website for the WIUT Hackathon 2026 CV track (team Ctrl+Alt+Elite): approach, EDA of the sample
videos, results with interactive timelines and risk curves, and a live demo backed by the API in
[traffic-event-detection/demo](https://github.com/Ctrl-Alt-Elite-newuu/traffic-event-detection/tree/main/demo).

React + TypeScript + Vite, no chart library (charts are plain SVG components in `src/components`).

## Develop

```bash
npm install
npm run dev                                   # http://localhost:5173, proxies /api to localhost:8000
DEMO_API=http://localhost:8001 npm run dev    # if the demo API runs on another port
```

Run the demo API from the backend repository: `uvicorn demo.app:app --port 8000`.

## Content and data

| What | Where |
|---|---|
| Team, report, links (plain text) | `src/content/site.ts` — search for `TODO` |
| EDA data and figures | `public/data/videos.json`, `public/data/eda/` — generated by `scripts/export_site_data.py` in the backend repo |
| Model output per sample video | `public/data/results/<video>.json` — `{ "events": [[start, end, label], ...], "risk": [[t, score], ...], "annotated_video"?: "results/<video>.mp4" }` |

## Build and deploy

`npm run build` writes the static site to `dist/`. Work goes to the `dev` branch and reaches `main`
through a pull request. The workflow lints and builds on every push to `dev`, on pull requests and on
`main`; only a merge into `main` deploys, copying `dist/` to the team server once the repository
variable `DEPLOY_ENABLED` is `true` (see `deploy/README.md` in the backend repository for the server
and secrets).
